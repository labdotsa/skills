# UX foundations

Use these sources as decision aids. Paraphrase the relevant idea and cite the source in the finding. Do not copy source catalogs or treat a named principle as proof.

| Source | Audit use | Authority boundary |
| --- | --- | --- |
| [Laws of UX](https://lawsofux.com/) | Generate hypotheses about grouping, attention, memory, choice, predictability, and effort. | A principle collection. Confirm relevance against the task and observed evidence. |
| [Nielsen's 10 heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/) | Inspect visibility, system match, control, consistency, error prevention and recovery, recognition, efficiency, and restraint. | Inspection vocabulary. A heuristic match is not user research or conformance. |
| [GOV.UK Design System](https://design-system.service.gov.uk/) | Compare task-led content, forms, error recovery, navigation, and inclusive service patterns. | Adapt patterns to product context. Do not copy its visual language or public-service assumptions. |
| [Inclusive Components](https://inclusive-components.design/) | Check semantic, resilient component behavior and inclusive interaction patterns. | Use current WCAG and WAI-ARIA APG for exact web semantics and widget behavior. |
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/design-principles) | Apply Purpose, Agency, Responsibility, Familiarity, Flexibility, Simplicity, Craft, and Delight to every target. | Principles transfer. Apple-specific controls, gestures, typography, and chrome require target-native adaptation. |

## HIG as an essential universal lens

Ask for every target:

- Purpose: Is the task and next useful action clear?
- Agency: Can the person control, interrupt, undo, decline, and recover?
- Responsibility: Are defaults, cost, data use, errors, and system responsibility understandable?
- Familiarity: Does the interaction use concepts the audience can recognize?
- Flexibility: Does it adapt to content, language, ability, context, and input mode?
- Simplicity: Has complexity been removed from the task rather than hidden in decoration?
- Craft: Are semantics, states, performance, and accessibility treated as part of quality?
- Delight: Does polish support confidence and clarity without distracting from the task?

For web, use [WCAG 2.2](https://www.w3.org/TR/WCAG22/) and the [WAI-ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) for semantics, keyboard behavior, focus, and widgets. For Android, iOS, desktop, TV, voice, and other targets, consult current platform guidance for navigation, focus, touch or remote targets, system chrome, dynamic type, gestures, interruption, and motion. Record the adapter and user benefit when departing from a convention.
