# IBM Plex Sans Arabic

The thumbnail publication pipeline uses the local `regular.ttf`, `medium.ttf`, and `bold.ttf` files because Satori does not parse the WOFF2 files used by the browser application.

These files are the same IBM Plex Sans Arabic 400, 500, and 700 font assets used by LAB's public website. IBM Plex is distributed under the SIL Open Font License 1.1; the license text is retained in `OFL-1.1.txt`.

Upstream project: <https://github.com/IBM/plex>
