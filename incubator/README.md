# Incubator

This directory holds public skill drafts that are not ready to install.

Drafts use `incubator/<skill-name>/DRAFT.md`. Do not name a draft `SKILL.md`; compatible agents and installers may otherwise treat it as published.

- [Security audit](security-audit/DRAFT.md) combines source review, independent validation, agent-package inspection, and security-fix verification. It remains a draft pending broader behavioral trials and comparative evaluation.

When a draft is proven and ready, promote it by creating `skills/<skill-name>/SKILL.md` and remove the incubator copy.
