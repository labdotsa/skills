# LAB Skills

LAB Skills publishes reusable agent knowledge and the paths for applying it.

## Language

**Skill**:
A stable, installable package of focused agent instructions whose root is `SKILL.md`.
_Avoid_: Protocol, prompt pack

**Recipe**:
A sequenced delivery playbook that composes skills, conversations, artifacts, and handoffs toward an outcome.
_Avoid_: Workflow template, tutorial

**Catalog**:
The complete derived index of stable Skills and published Recipes.
_Avoid_: Database, CMS

**Discovery Site**:
The public browsing and reading experience generated from the Catalog and its source content.
_Avoid_: Admin site, source site

**Source Content**:
The canonical Skill and Recipe documents and their owned supporting files.
_Avoid_: Page copy, CMS content

**Publication Artifact**:
Generated static files that can be deployed but are never edited as source.
_Avoid_: Website source, second codebase
