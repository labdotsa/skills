# Skill template

To create a stable skill:

1. Copy this directory to `skills/<skill-name>/`.
2. Rename `SKILL.template.md` to `SKILL.md`.
3. Replace all template values and instructions.
4. Keep only the optional directories the skill actually needs.
5. Run `npm run catalog` and `npm run validate`.

For an incubating skill, begin with `incubator/<skill-name>/DRAFT.md` instead. Do not copy a file named `SKILL.md` into the incubator.
