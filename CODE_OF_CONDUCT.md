# Code of Conduct

We want this repository to be a welcoming place for practical, thoughtful collaboration.

## Expected behavior

- Be respectful, specific, and constructive.
- Critique ideas and outcomes, not people.
- Share enough context for others to reproduce a problem.
- Respect privacy, confidentiality, and intellectual property.
- Accept maintainer decisions about scope and maturity without hostility.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate disruption, and publishing another person's private information are not tolerated.

## Enforcement

Maintainers may edit or remove contributions and restrict participation when behavior violates these expectations. Security or privacy-sensitive reports should follow [SECURITY.md](SECURITY.md), not public issues.
