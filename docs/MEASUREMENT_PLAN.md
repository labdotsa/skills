# Collection hero measurement plan

## Search outcomes

| KPI | Source | Baseline | Review cadence | Decision rule |
| --- | --- | --- | --- | --- |
| Organic impressions by collection page and query | Google Search Console | First complete 28 days after deployment | Every 28 days | Investigate intent mismatch when relevant impressions rise but CTR declines. |
| Organic clicks and CTR | Google Search Console | First complete 28 days after deployment | Every 28 days | Compare equivalent 28-day periods; do not attribute short-term movement to copy alone. |
| Indexed canonical collection pages | Search Console URL inspection / coverage | Both canonical collection URLs expected | After deployment and monthly | Escalate any canonical, noindex, or rendering conflict. |

## Product outcomes

| KPI | Source | Baseline | Review cadence | Decision rule |
| --- | --- | --- | --- | --- |
| Hero-to-catalog CTA activation | Privacy-conscious first-party event count | Not yet available | 28 days after deployment | Retain descriptive labels; test one CTA wording dimension only if engagement is weak. |
| Skills-to-Recipes and Recipes-to-Skills navigation | Privacy-conscious first-party event count | Not yet available | 28 days after deployment | Use directional comparison only; do not infer user intent without qualitative evidence. |

No baseline or improvement percentage is asserted before field data exists. Core Web Vitals, canonical integrity, and structured-data validity remain governed by the repository's existing SEO and publication quality gates.
